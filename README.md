
# 🇪🇸 Versión en Español

🎉 Birthday GIFt – Página de Cumpleaños Interactiva

Este proyecto es una pequeña página web creada con HTML y CSS que muestra una felicitación de cumpleaños interactiva.
Incluye imágenes, efectos hover y un diseño colorido pensado para dedicar a un amigo o familiar.

El proyecto forma parte de una práctica del curso de HTML & CSS.

🌟 Características

Diseño colorido con gradiente de fondo.

Foto del cumpleañero en estilo circular.

Varios “regalos” interactivos: al pasar el ratón por encima, cada tarjeta muestra un GIF diferente.

Código sencillo y fácil de modificar para personalizar para otra persona.

Totalmente responsivo de forma básica gracias al centrado y uso de unidades flexibles.

# 🇬🇧 English Version

🎉 Birthday GIFt – Interactive Birthday Webpage

This project is a small, fun birthday webpage built with HTML and CSS.
It displays a birthday greeting with interactive “gift” boxes that reveal GIFs when hovered over.
The page is colorful, simple, and easy to customize for a friend or family member.

This project was created as part of an HTML & CSS learning exercise.

🌟 Features

Bright, colorful gradient background

Circular profile image of the birthday person

Multiple interactive gift cards: hovering reveals a different GIF

Easy to personalize for any recipient

Basic responsive layout using centered elements and flexible sizing
